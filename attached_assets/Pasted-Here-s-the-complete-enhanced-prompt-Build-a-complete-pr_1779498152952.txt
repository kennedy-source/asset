---

Build a complete, production-ready Business Management System called **PAJOY Smart Business System** for a clothing, school uniform, and embroidery business in Kenya. This must be enterprise-grade, feature-rich, and ready for real business use.

## Tech Stack
- **Frontend:** React + TypeScript + Vite + Tailwind CSS + shadcn/ui + Wouter + React Query + Recharts
- **Backend:** Node.js + Express + TypeScript + Drizzle ORM
- **Database:** PostgreSQL 16
- **Cache:** Redis (for sessions, rate limiting, queues)
- **Deployment:** Docker + Docker Compose
- **Payments:** Paystack (M-Pesa, Card, Bank)
- **AI:** Anthropic Claude API
- **Email:** Nodemailer + SMTP
- **PDF:** Puppeteer or PDFKit
- **File Storage:** Local with option for S3/Cloudflare R2
- **Background Jobs:** Bull Queue with Redis

---

## Business Context
- Clothing shop, school uniform supplier, and embroidery/printing business in Nairobi, Kenya
- Currency: Kenya Shillings (KSh)
- VAT: 16% (configurable)
- Multi-branch capable
- Multi-user with granular permissions
- Roles: super_admin, admin, manager, cashier, production_staff, accountant

## Paystack Integration

### M-Pesa STK Push
```typescript
POST /api/payments/paystack/mpesa
{
  invoiceId?: number,
  saleId?: number,
  phone: string,        // 0712345678 or 254712345678
  amount: number,
  description: string
}
// Response: { reference, status, message }

// Poll for status:
GET /api/payments/paystack/verify/:reference
```

### Card Payment
```typescript
POST /api/payments/paystack/initialize
{
  invoiceId?: number,
  saleId?: number,
  email: string,
  amount: number,
  callback_url: string
}
// Response: { authorizationUrl, reference, accessCode }
```

### Webhook (auto-update payment status)
```typescript
POST /api/payments/paystack/webhook
// Verify HMAC signature with PAYSTACK_WEBHOOK_SECRET
// On charge.success: mark invoice/sale as paid
// On transfer.success: record payment
// Send email receipt to customer
```
